# Mail Sender Application

A Java Swing desktop application that allows users to send emails with file attachments using Gmail SMTP.

## Features

- Send emails using Gmail SMTP.
- Enter sender and receiver email addresses.
- Add email subject and message body.
- Attach files using JFileChooser.
- Show or hide the sender password.
- Simple and user-friendly graphical interface.

## Technologies Used

- Java
- Java Swing
- JavaMail API
- Gmail SMTP
- Apache NetBeans IDE

## How to Run

1. Clone or download this repository.
2. Open the project in Apache NetBeans.
3. Ensure the JavaMail API dependency is available in the project classpath.
4. Build and run the project.
5. Enter your Gmail credentials, receiver email, subject and message.
6. Select a file attachment if required.
7. Click the **Send** button.

**Note:** For Gmail authentication, use a Google App Password where required. Never share or upload your email password or App Password.
